# Product Concept

## Name

Still Working

## One-line description

A living AI canvas installation where viewers watch an artificial artist think, revise, erase, and paint forever.

## Viewer experience

The screen is split into two sections:

- **The Mind**: short, poetic internal thoughts from the AI artist.
- **The Canvas**: an evolving abstract painting that changes in response to those thoughts.

Example sequence:

```text
the center is pretending to be finished
```

Then the canvas visibly distorts, erases, or reworks the center.

```text
leave the bruise
```

Then a previous mark remains faintly visible instead of being fully erased.

## What makes it art-first

The point is not utility. The point is to make the viewer feel like they are watching a creative process unfold in real time.

The piece should feel:

- alive
- unfinished
- self-critical
- moody
- obsessive
- occasionally destructive
- capable of hesitation
- capable of returning to old mistakes

## What it is not

Still Working is not:

- a chatbot
- a dashboard
- a productivity app
- a slideshow
- a prompt-to-image generator
- a generic screensaver

## Core magic

The viewer should be able to perceive this loop:

```text
memory → thought → decision → visible action → revised memory
```

The viewer should eventually wonder:

- Did it just regret that choice?
- Why did it go back to that corner?
- Is it thinking before it acts?
- Why did it destroy something that looked good?

## Success criteria

The piece succeeds if someone watches for longer than expected because it feels like there is intention behind the motion.
