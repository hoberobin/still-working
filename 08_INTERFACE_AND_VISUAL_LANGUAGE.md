# Interface and Visual Language

## Screen layout

Use a split-screen layout.

Recommended proportions:

- 35–40% left panel: The Mind
- 60–65% right panel: The Canvas

The interface should feel like an art installation, not software.

## The Mind panel

Show:

- current thought
- 3–7 previous thoughts fading
- current mood, small and subtle
- pulse indicator

Do not show:

- chat input
- buttons
- menus
- analytics
- debug data in normal mode

## Thought typography

Recommended style:

- lowercase
- generous spacing
- quiet, minimal type
- current thought larger
- previous thoughts lower opacity

Thoughts should feel like studio fragments.

## Canvas visual language

The painting should be abstract, layered, imperfect, and visibly revised.

Use:

- translucent washes
- imperfect lines
- texture/grain
- visible erasures
- ghost marks
- color bleeding
- scars/scratches
- asymmetry

Avoid:

- perfect geometric UI shapes
- clip-art visuals
- literal objects
- faces/characters in MVP
- polished logo-like compositions

## Color system

Start with 2–3 curated palettes.

### Muted Studio

- off-white / warm gray base
- charcoal
- rust
- muted blue
- olive/green-gray
- pale ochre

### Dream

- deep blue-gray
- lavender-gray
- pale cyan
- muted rose
- smoky violet

### Brutalist

- near-black
- bone white
- red oxide
- gray
- dull yellow

Do not randomly choose fully saturated colors constantly. Let colors evolve slowly.

## Mood to visual mapping

### Calm

- lower contrast
- slower motion
- soft washes
- thin strokes

### Restless

- more jitter
- repeated marks
- region switching
- uneven pulse

### Frustrated

- harsh contrast
- scars
- erasures
- abrupt gestures

### Dreaming

- blur
- drifting washes
- soft overlays
- lower edge definition

### Obsessive

- repeated region targeting
- small variations
- visible overworking

## Installation feel

The piece should invite someone to watch without needing instructions.

The viewer should understand:

- the left side is thought
- the right side is action
- the system is alive/in-process
